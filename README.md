2026년 2학기 **Unity 기초 스터디**

## 📌 스터디 목표

- Unity 기본 사용법 익히기
- 2D 게임의 기본적인 구조 이해
- 캐릭터 이동 및 물리 구현
- 게임 기믹 구현
- 씬 전환 및 게임 루프 구성
- 간단한 UI 및 클리어 연출 구현
- GitHub를 활용한 프로젝트 관리 경험

---

## 🗓️ 스터디 일정

총 **5회차**로 진행합니다.

### 1회차 — 스터디 및 개발 환경 설정

- 스터디 진행 방식 및 프로젝트 소개

### 2회차 — 캐릭터 물리 및 이동

플레이어 캐릭터의 기본적인 움직임을 구현합니다.

- 좌우 이동
- 점프
- 중력 및 Rigidbody2D
- 기본적인 캐릭터 물리
- 플랫폼 위 이동

### 3회차 — 게임 기믹

플레이어의 행동에 반응하는 간단한 게임 기믹을 구현합니다.

- 무너지는 발판
- 가시 등의 장애물
- 충돌 및 트리거 처리
- 기믹을 활용한 스테이지 구성

### 4회차 — 화면 전환 및 게임 루프

게임의 기본적인 진행 구조를 구현합니다.

- 방(씬) 이동
- 화면 전환
- 플레이어 사망 판정
- 체크포인트
- 재시작 및 게임 진행 흐름 구성

### 5회차 — 클리어 연출 및 빌드

게임의 마무리 요소를 구현하고 실제 빌드까지 진행합니다.

- 도착 지점 구현
- 클리어 판정
- 플레이어 조작 차단
- 클리어 텍스트 UI
- 게임 종료 처리
- 프로젝트 Build
